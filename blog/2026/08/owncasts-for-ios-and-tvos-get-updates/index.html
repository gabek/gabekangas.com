Owncasts for iOS and tvOS get updates!

In 2024 “Owncasts” for iOS was released as a side project to give a native interface on the iPhone and AppleTV. I highly recommend you read the first post in this series: Owncasts for iOS and tvOS. It will detail what the goal with the application were, and how it came to life.

It was something that wasn’t directly connected to or maintained by the Owncast project. And it hadn’t been touched much since then. But I did have a list of things I wished it could do. But I just never got to them.

Until now! Today a new release is out, and it finally has most of the functionality originally wished for.

You can chat! Link to heading

You can finally chat while mobile. On AppleTV you can just follow along, since typing with a remote really sucks. It doesn’t support chat auth, though. So if people find themselves using it, let me know.

Mobile live streaming! Link to heading

If you’re an Owncast streamer, you can now stream live FROM the application. Put in your stream details into settings, and you can do live mobile live streaming. I think that’s neat. Let me know how it works for you. The real world network connectivity makes this kind of challenging, so I’m curious how it goes.

iPad no longer sucks! Link to heading

It used to suck. Now (especially in landscape) it’s pretty nice.

So check it out and let know what you think. As previously stated, this is a side project with no promises of features
